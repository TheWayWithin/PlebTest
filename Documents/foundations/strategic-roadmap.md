# Strategic Roadmap

**Business Name:** PlebTest
**Date:** January 12, 2026
**Version:** 1.0

---

## Executive Summary

PlebTest helps founders who won't pick up the phone validate ideas using AI customer simulations. This roadmap maps the path from Landing Page (tomorrow) through Year 1 targets (1,000 founders, $250K ARR).

---

## Section 1: Vision to Execution Bridge

### 10-Year Vision
> "The fear of customer discovery no longer stops anyone. Founders launch knowing, not hoping."

### 5-Year BHAG (2031)
- 50,000 founders using PlebTest
- $7.5M ARR
- 10,000+ products launched
- Credited with helping launch 10 unicorns

### 3-Year Strategic Goals (2029)
1. **Scale** - 15,000 active founders, $2M ARR
2. **Proof** - 500+ public success stories (kills, pivots, launches)
3. **Product maturity** - Full self-serve platform with enterprise/team features

### 1-Year Objectives (2026)
1. **Launch & validate** - MVP live, 1,000 paying founders
2. **Revenue** - $250K ARR
3. **Proof points** - 20 public case studies proving kill/pivot/build value

## Section 2: Product Evolution Path

### Phase 0: Landing Page (Tomorrow)

**Theme:** Start capturing demand before MVP exists

**Scope:**
- Landing page with positioning
- Email/waitlist capture
- Basic analytics

**Success Criteria:**
- Live and collecting signups

---

### Phase 1: Basic MVP (End January 2026)

**Theme:** Core loop working - private testing only

**Scope:**
- Single idea input flow
- AI persona simulation (3-5 personas)
- Anti-sycophancy engine active
- Kill/Pivot/Build verdict
- Basic report
- OAuth (login system)
- Payment integration (ready for Phase 2)

**Purpose:** Validate the core experience works before going live.

**Success Criteria:**
- You complete 5+ test validations
- Core loop feels solid
- No critical bugs blocking launch

---

### Phase 2: Public Launch (February 2026)

**Theme:** Full MVP live - the complete validation experience

**Scope:**
- Everything from Phase 1, plus:
- Spectator Mode (watch full simulated conversations)
- Persona customization (define your target customer)
- Pivot suggestions (show *how* to pivot, not just "pivot")
- Saved history / idea portfolio
- Shareable verdict cards (social-ready visuals)
- Shareable report links (opt-in public sharing)

**Success Criteria:**
- First paying customers
- 60%+ trial-to-paid conversion
- Early case studies emerging

---

### Phase 3: Scale (March - December 2026)

**Theme:** Growth and ecosystem

**Scope:**
- Team/agency accounts
- API access for integrations
- Advanced reporting (export, share with investors)
- Community features (anonymous benchmarking)
- Enterprise pilots
- Multi-language support (common languages as demand shows)

**Success Criteria:**
- 1,000 paying founders
- $250K ARR run rate
- 20 public case studies

## Section 4: Risks & Priorities

### Key Risks

| Risk | Likelihood | Mitigation |
|------|------------|------------|
| **Solo Founder Capacity** - building, marketing, supporting alone | High | Ruthless scope control. Cut features fast. Automate support where possible. |
| **Anti-Sycophancy Quality** - if AI isn't challenging enough, core value prop fails | Medium | Heavy testing during Phase 1. Build feedback loop to catch when verdicts feel "too easy." |
| **User Acquisition** - getting first 100 paying customers | Medium | Build in public. Shareable verdict cards drive organic discovery. Early case studies prove value. |
| **"Just Use ChatGPT" Objection** - founders think they can DIY for free | High | Time is the killer differentiator (hours vs minutes). Persona depth via demographic/psychographic/trait dials is hard to replicate. Anti-sycophancy built in. |

---

### What We're NOT Doing

| Not Doing | Reason |
|-----------|--------|
| **B2B / Enterprise First** | Focus is solo founders. Enterprise comes in Phase 3 as pilots, not priority. |
| **Building a Community Platform** | Focus is the core product. Community can come later if users want it. |
| **Multi-Language Support (Year 1)** | English-speaking founders first. Post-MVP, add common languages as demand shows. |
| **Done-For-You Validation Services** | PlebTest is self-serve product only. Keeps focus and scales better. |
